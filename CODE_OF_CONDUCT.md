# Code of Conduct — OUJAI Graduation Project Team

## Our Pledge
As a four-student graduation project team, we pledge to maintain a respectful, constructive, and accountable engineering environment throughout our 18-week project lifecycle.

## Our Standards
- **Constructive Code Reviews:** Critique code, schemas, and architectural trade-offs—never teammates.
- **Contract Respect:** Communicate breaking changes in APIs, MQTT schemas, or KPI definitions early before blocking another member's milestone.
- **Academic Integrity:** Document model metrics honestly (including when a seasonal-naive baseline outperforms a complex model on synthetic data) and never fabricate test results or live hospital validation claims.
- **Timely Unblocking:** Respond to Pull Request review requests within 24 hours on working days so no teammate is blocked.
